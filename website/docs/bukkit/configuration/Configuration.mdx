Main file: `plugins/DoubleDoors/config.yml`

## Full Key Reference

### Core Features

#### enableRecursiveOpening

- Type: boolean
- Default: true
- Effect: Master gate for linked synchronization logic.
- Note: In current behavior, when false, linked state application is skipped for player, redstone, and villager paths.

#### recursiveOpeningMaxBlocksDistance

- Type: integer
- Default: 10
- Allowed range: 1 to 32
- Effect: BFS depth limit for connected same-type gate/trapdoor searches.
- Internal clamp: values below 1 become 1, above 32 become 32.

#### enableDoors

- Type: boolean
- Default: true
- Effect: Enables door handling when a block type name ends with _DOOR.

#### enableFenceGates

- Type: boolean
- Default: true
- Effect: Enables fence-gate handling when type ends with _FENCE_GATE.

#### enableTrapdoors

- Type: boolean
- Default: true
- Effect: Enables trapdoor handling when type ends with _TRAPDOOR.

#### enableVillagerLinkedDoors

- Type: boolean
- Default: true
- Effect: Enables villager-driven open and close synchronization.

### Auto-Close

#### enableAutoClose

- Type: boolean
- Default: false
- Effect: When true, player-triggered linked opens will automatically close after a configurable delay.
- Note: Redstone-powered blocks are skipped when auto-close fires.

#### autoCloseDelaySeconds

- Type: integer
- Default: 5
- Allowed range: 1 to 300
- Effect: Seconds to wait before auto-close fires after a player-triggered open.

### Knock Feature

#### enableKnockFeature

- Type: boolean
- Default: true
- Effect: Allows players to left-click doors to play a knock sound audible to nearby players.

#### knockDistanceBlocks

- Type: integer
- Default: 12
- Allowed range: 1 to 64
- Effect: Maximum distance in blocks at which the knock sound can be heard.

### Sound and Visual Feedback

#### playPartnerSound

- Type: boolean
- Default: true
- Effect: Play sound at linked partner blocks on state change.

#### partnerSound

- Type: string
- Default: "" (none)
- Effect: Global override sound for linked updates. Use Bukkit sound names, e.g. `BLOCK_WOODEN_DOOR_OPEN`.

#### partnerSoundOverrides

- Type: map with keys `doors`, `fenceGates`, `trapdoors`
- Default: all empty (use global sound)
- Effect: Per-type sound overrides that take precedence over the global `partnerSound`.

#### enablePartnerParticles

- Type: boolean
- Default: false
- Effect: Emit particles on the linked partner block when it updates.

#### partnerParticle

- Type: string
- Default: END_ROD
- Effect: Particle type for partner effects. Use Bukkit particle names.

#### partnerParticleCount

- Type: integer
- Default: 6
- Allowed range: 1 to 64
- Effect: Number of particles spawned per partner update.

### Animation Sync

#### animationSyncExtraDelayTicks

- Type: integer
- Default: 0
- Allowed range: 0 to 4
- Effect: Extra ticks before mirroring partner state. Increase if partner doors appear out of sync due to client animation timing.

### Preview Command

#### previewParticle

- Type: string
- Default: WAX_OFF
- Effect: Particle type used by `/doubledoors preview`.

#### previewParticleCount

- Type: integer
- Default: 18
- Allowed range: 1 to 128
- Effect: Number of particles per preview burst.

#### previewDurationTicks

- Type: integer
- Default: 60
- Allowed range: 20 to 200
- Effect: How long preview particles run in ticks.

### Performance

#### lookupCacheTtlMillis

- Type: integer
- Default: 1200
- Allowed range: 200 to 10000
- Effect: Cache TTL for mirrored door lookups in milliseconds. Lower values reduce stale-cache risk but increase lookups.

#### interactionCooldownMillis

- Type: integer
- Default: 250
- Allowed range: 0 to 5000
- Effect: Cooldown in milliseconds before the same player can toggle the same block again. Set to 0 to disable.

### Location Filters

#### locationFilter.mode

- Type: string
- Default: DISABLED
- Allowed values: DISABLED, BLACKLIST, WHITELIST
- Effect: When BLACKLIST, linked behavior is disabled at listed locations. When WHITELIST, linked behavior is only enabled at listed locations.

#### locationFilter.locations

- Type: list of strings
- Default: [] (empty)
- Effect: List of locations in `world:x:y:z` format. Coordinates are integers.

### WorldGuard Compatibility

#### worldGuardRegionFilter.mode

- Type: string
- Default: DISABLED
- Allowed values: DISABLED, BLACKLIST, WHITELIST
- Effect: When BLACKLIST, linked behavior is disabled inside listed regions. When WHITELIST, linked behavior is only enabled inside listed regions.

#### worldGuardRegionFilter.regions

- Type: list of strings
- Default: [] (empty)
- Effect: WorldGuard region IDs to apply the filter to.

#### worldGuardCustomFlag

- Type: string
- Default: double-doors-allow
- Effect: Custom WorldGuard state-flag name. Can be set per-region to `allow` or `deny` DoubleDoors behavior.

#### worldGuardRespectBuildPermission

- Type: boolean
- Default: true
- Effect: Enforce WorldGuard build permission for linked actions.

#### worldGuardRespectUseFlag

- Type: boolean
- Default: true
- Effect: Enforce WorldGuard USE flag for linked actions.

### GriefPrevention Compatibility

#### griefprevention.requireBuildForLinkedDoors

- Type: boolean
- Default: false
- Effect: When true, requires Build trust (instead of Access trust) for linked partner door toggling inside claims.

### Global Toggle

#### serverWideEnabled

- Type: boolean
- Default: true
- Effect: Global kill switch for all plugin behavior.
- Runtime toggle command: `/doubledoors server-toggle`

### Analytics

#### enableAnonymousTracking

- Type: boolean
- Default: true
- Effect: Enable anonymous usage metrics via FastStats. All data is public at https://faststats.dev/project/double-doors-server

See [Telemetry](../../concepts/telemetry) for the full collection, storage, and usage details.

### Language

#### language

- Type: string
- Default: en_US
- Effect: Server-wide language code. Console logs always use this language.

#### perPlayerLocaleEnabled

- Type: boolean
- Default: false
- Effect: Allow players to set their own locale via `/doubledoors locale`. Console always uses the server language.

### SQL Storage

#### sql.enabled

- Type: boolean
- Default: false
- Effect: Enable SQL-backed storage for player preferences and claim settings. When disabled, YAML files are used.

#### sql.jdbcUrl

- Type: string
- Default: jdbc:sqlite:plugins/DoubleDoors/doubledoors.db
- Effect: JDBC connection URL. Supports SQLite and MySQL.

#### sql.username

- Type: string
- Default: "" (empty)
- Effect: SQL username. Leave empty for SQLite.

#### sql.password

- Type: string
- Default: "" (empty)
- Effect: SQL password. Leave empty for SQLite.

#### sql.migrateFromYaml

- Type: boolean
- Default: true
- Effect: One-time import from existing YAML files when SQL is first enabled.

#### sql.proxyHeartbeatMaxAgeSeconds

- Type: long
- Default: 180
- Minimum: 15
- Effect: Maximum accepted age of proxy heartbeats for Geyser/Floodgate detection via shared SQL database.

### Update Checker

#### updateChecker.enabled

- Type: boolean
- Default: true
- Effect: Enable built-in Modrinth update checker. Automatically disabled when a standalone `PluginUpdater` plugin is detected.

#### updateChecker.checkScheduleSeconds

- Type: integer
- Default: 3600
- Allowed range: 300 to 86400
- Effect: Seconds between update checks.

#### updateChecker.notify

- Type: boolean
- Default: true
- Effect: Notify players with the `doubledoors.update.notify` permission when an update is available.

### Debug

#### debug

- Type: boolean
- Default: false
- Effect: Enable verbose console logging for troubleshooting.

## Example Config

```yaml
# Core
enableRecursiveOpening: true
recursiveOpeningMaxBlocksDistance: 10
enableDoors: true
enableFenceGates: true
enableTrapdoors: true
enableVillagerLinkedDoors: true
serverWideEnabled: true

# Auto-close
enableAutoClose: false
autoCloseDelaySeconds: 5

# Knock
enableKnockFeature: true
knockDistanceBlocks: 12

# Sound and visual
playPartnerSound: true
partnerSound: ""
partnerSoundOverrides:
  doors: ""
  fenceGates: ""
  trapdoors: ""
enablePartnerParticles: false
partnerParticle: END_ROD
partnerParticleCount: 6

# Animation sync
animationSyncExtraDelayTicks: 0

# Preview
previewParticle: WAX_OFF
previewParticleCount: 18
previewDurationTicks: 60

# Performance
lookupCacheTtlMillis: 1200
interactionCooldownMillis: 250

# Filters
locationFilter:
  mode: DISABLED
  locations: []
worldGuardRegionFilter:
  mode: DISABLED
  regions: []
worldGuardCustomFlag: double-doors-allow
worldGuardRespectBuildPermission: true
worldGuardRespectUseFlag: true

# GriefPrevention
griefprevention:
  requireBuildForLinkedDoors: false

# Language
language: en_US
perPlayerLocaleEnabled: false

# SQL
sql:
  enabled: false
  jdbcUrl: jdbc:sqlite:plugins/DoubleDoors/doubledoors.db
  username: ""
  password: ""
  migrateFromYaml: true
  proxyHeartbeatMaxAgeSeconds: 180

# Update checker
updateChecker:
  enabled: true
  checkScheduleSeconds: 3600
  notify: true

# Debug
debug: false
```

## Reload Behavior

Use `/doubledoors reload` to reload:

- config.yml
- players.yml cache

No full server restart is required for normal config edits.
