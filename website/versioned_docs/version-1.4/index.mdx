DoubleDoors is a Paper/Spigot plugin for synchronized door-like blocks.
It supports mirrored double doors, recursive groups for gates and trapdoors, redstone sync, and villager-triggered sync.

## At a Glance

- Minecraft API target: Paper/Spigot 1.21+
- Java target: Java 25+
- Main command: /doubledoors
- Core permissions: doubledoors.use, doubledoors.toggle, doubledoors.reload, doubledoors.server-toggle
- Build command: ./gradlew build
